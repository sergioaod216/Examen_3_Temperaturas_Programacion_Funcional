
# Examen 3 - Programación Funcional

Programa en Java que trabaja con las temperaturas de diferentes ciudades.

## Funciones del programa

- Lee los datos del archivo Temperaturas.csv.
- Permite seleccionar un rango de fechas.
- Muestra una gráfica de barras con el promedio de temperatura de cada ciudad.
- Permite seleccionar una fecha para consultar la ciudad más calurosa y la menos calurosa.

## Cómo ejecutar el programa

1. Abrir el proyecto en Visual Studio Code.
2. Abrir el archivo src/App.java.
3. Presionar Run para ejecutar el programa.
